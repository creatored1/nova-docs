# Установка NOVA Assistant

> **Скачать:** [nova-assistant.ru/download](https://nova-assistant.ru/download) · [GitHub Releases](../../releases)

Актуальный релиз: **0.3.4**. Один NSIS-установщик x64 подходит для Windows 10 и Windows 11.

---

## Системные требования

| Компонент | Требование |
|---|---|
| ОС | Windows 10 (1903+) 64-бит или Windows 11 |
| Место на диске | Установщик 0.3.4 — около 333 МБ; оставьте запас под модели Whisper и данные |
| Интернет | Нужен для входа, облачного STT/TTS и ИИ-ответов |
| Микрофон | Нужен для голосовых команд; подойдёт встроенный или внешний |

## Установка

### 1. Запустите установщик

Дважды кликните по скачанному `.exe`. Если Windows SmartScreen покажет предупреждение, проверьте источник файла и выберите **«Подробнее» → «Всё равно запустить»**.

### 2. Выберите параметры

В мастере установки:

- выберите папку установки;
- при необходимости включите ярлык на рабочем столе;
- нажмите **Установить**.

Установщик работает в пользовательском режиме и не требует установки приложения для всех пользователей Windows.

### 3. Пройдите первый запуск

1. Разрешите NOVA доступ к микрофону.
2. В Setup Wizard выберите микрофон и выполните короткую проверку записи.
3. Войдите через Telegram или VK ID.
4. Выберите язык и сохраните настройки.

Для Free по умолчанию используется **DeepSeek V4 Flash** через NOVA. Для Pro по умолчанию доступен **Gemini 3.1 Flash Lite**.

### 4. Проверьте голос

На дашборде нажмите кнопку микрофона, скажите:

> **«Привет, Нова»**

Нажмите кнопку ещё раз для завершения разговора. Если включено автоопределение тишины, запись может завершиться автоматически.

## Настройка микрофона

1. В Windows откройте **Пуск → Параметры → Конфиденциальность → Микрофон** и разрешите доступ приложениям.
2. В **Пуск → Параметры → Система → Звук → Вход** выберите нужное устройство.
3. В NOVA откройте **Настройки → Голос → Устройство ввода**.
4. Если голос распознаётся плохо, проверьте усиление микрофона и порог VAD в настройках NOVA.

Free использует локальный Whisper. В Pro можно выбрать локальный Whisper или облачный Deepgram; для Deepgram нужен настроенный доступ на стороне сервиса.

---

## Wake word и Brain v3

В **Настройки → Голос** находятся переключатели **Wake word**, фонового прослушивания и фразы активации.

- Wake по умолчанию выключен.
- При включении используется цепочка **VAD → распознавание речи → проверка фразы активации**; Porcupine не используется.
- После активации можно продолжать диалог без повторного wake примерно 10 минут.
- Кнопка микрофона дашборда и фоновое прослушивание используют общий микрофон.

Если wake выключен, используйте кнопку микрофона на дашборде.

## Обновление

NOVA проверяет новую версию при запуске через `electron-updater`. При доступном обновлении в приложении появляется уведомление **«Доступно обновление»**.

Обновление устанавливается в каталог уже установленного приложения. Кнопка **«Позже»** закрывает уведомление только на текущий запуск; при следующем запуске оно появится снова, пока новая версия доступна.

Для ручной переустановки скачайте новый `NOVA-Assistant-Setup-x64.exe` с [сайта](https://nova-assistant.ru/download).

## Удаление

Откройте **Пуск → Параметры → Приложения → Установленные приложения → NOVA Assistant → Удалить**.

Пользовательские настройки и локальные данные находятся в:

```text
%APPDATA%\nova-assistant-desktop\
```

Для полной очистки после удаления приложения удалите эту папку вручную. Это также удалит локальные настройки, историю и сохранённые локальные ключи.

## Проблемы

| Симптом | Что проверить |
|---|---|
| SmartScreen показывает предупреждение | Скачайте файл только с официального сайта или GitHub Releases; затем выберите «Подробнее» → «Всё равно запустить» |
| Установщик не запускается | Выполните `winver`: нужна Windows 10 версии 1903 или новее либо Windows 11 |
| NOVA не слышит голос | Разрешение микрофона Windows, выбранное устройство и раздел «Настройки → Голос» |
| Wake не реагирует | Включите Wake word и фоновое прослушивание; либо используйте кнопку микрофона |
| ИИ не отвечает | Проверьте вход в аккаунт и интернет; квота Free/Pro относится к chat и voice_turn |
| Нет озвучки | Проверьте громкость и выбранный TTS; для Pro Fish Audio можно заменить на Silero v4 |
