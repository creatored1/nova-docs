# Установка NOVA Assistant

> **Скачать:** [nova-assistant.ru/download](https://nova-assistant.ru/download)

Актуальный релиз: **0.4.4**. Один NSIS-установщик x64 для Windows 10 и Windows 11. Размер файла — около **287 МБ**.

Установщик **не подписан** цифровой подписью издателя. Windows и браузер могут показать предупреждения — это ожидаемо. Ниже — как безопасно установить приложение.

---

## Системные требования

| Компонент | Требование |
|---|---|
| ОС | Windows 10 (1903+) 64-бит или Windows 11 |
| Место на диске | Установщик ~287 МБ; оставьте запас под кэш и пользовательские данные |
| Интернет | Нужен для входа, распознавания речи, озвучки и ответов ИИ |
| Микрофон | Нужен для голоса и фонового прослушивания |

## Скачивание

Скачивайте только с [официальной страницы](https://nova-assistant.ru/download):

| Файл | Назначение |
|---|---|
| `NOVA-Assistant-Setup-x64.exe` | Актуальный установщик (псевдоним последней версии) |
| `NOVA-Assistant-Setup-0.4.4-x64.exe` | Версионный файл релиза 0.4.4 |

На сайте есть карточки Windows 10 и Windows 11 — это одна и та же сборка x64.

## Почему Windows предупреждает о файле

NOVA распространяется **без code signing** (без сертификата издателя в установщике). Поэтому:

1. Браузер может написать, что файл «может быть опасен».
2. SmartScreen Windows показывает **«Система Windows защитила ваш компьютер»** / *Windows protected your PC*.
3. Иногда срабатывает Защитник Windows с пометкой о неизвестном издателе.

Это **не означает**, что файл повреждён. Так бывает у многих независимых приложений без платной подписи. Главное — скачать установщик **только** с [nova-assistant.ru](https://nova-assistant.ru/download), а не со сторонних зеркал.

## Установка по шагам

### 1. Сохраните файл и проверьте источник

- Убедитесь, что адрес сайта именно `nova-assistant.ru`.
- Не открывайте установщик из писем и чатов неизвестных отправителей.

### 2. Если браузер блокирует скачивание

В Chrome / Edge: в списке загрузок нажмите **⋯ → Оставить** / **Keep**.  
При необходимости подтвердите **«Всё равно скачать»**.

### 3. SmartScreen при запуске установщика

1. Дважды кликните `NOVA-Assistant-Setup-x64.exe`.
2. Если появится синее окно SmartScreen:
   - нажмите **Подробнее** (*More info*);
   - затем **Всё равно запустить** (*Run anyway*).
3. Если Windows спрашивает разрешение администратора — подтвердите запуск (обычно достаточно прав текущего пользователя: установщик ставится в пользовательский каталог).

### 4. Мастер установки

- Выберите папку установки (или оставьте предложенную).
- При желании включите ярлык на рабочем столе.
- Нажмите **Установить** и дождитесь завершения.

### 5. Первый запуск

1. Разрешите NOVA доступ к **микрофону**, если Windows спросит.
2. Пройдите короткий Setup Wizard: микрофон и проверка записи.
3. Войдите через **Telegram** или **VK ID**.
4. При необходимости выберите язык интерфейса.

После входа:

- на тарифе **Free** по умолчанию ИИ — **DeepSeek V4 Flash** (через NOVA);
- на **Pro** по умолчанию доступны **Gemini 3.1 Flash Lite** и другие Pro-модели.

### 6. Проверьте голос

На дашборде нажмите кнопку микрофона, скажите коротко:

> **«Привет»**

Нажмите кнопку ещё раз, чтобы завершить разговор. Если включено автоопределение тишины, запись может остановиться сама.

Дальше настройте микрофон, wake и озвучку: [SETTINGS.md](./SETTINGS.md).

## Если Защитник Windows удаляет или блокирует файл

1. Откройте **Безопасность Windows → Защита от вирусов и угроз → Журнал защиты**.
2. Найдите действие по файлу NOVA и выберите **Восстановить** / разрешить.
3. Повторно скачайте установщик с официального сайта и добавьте папку загрузок или установки в исключения **только если** вы уверены в источнике файла.

Не отключайте антивирус целиком «на всякий случай».

## Настройка микрофона в Windows

1. **Параметры → Конфиденциальность и защита → Микрофон** — разрешите доступ приложениям (и desktop-приложениям).
2. **Параметры → Система → Звук → Ввод** — выберите нужное устройство.
3. В NOVA: **Настройки → Голос и микрофон**.

Подробности по всем разделам настроек: [SETTINGS.md](./SETTINGS.md).

---

## Голос после установки

В **Настройки → Пробуждение**:

- **Wake word** — требовать фразу активации («Нова», «NOVA» и ваши теги).
- **Фоновый режим** — слушать микрофон в фоне (иначе только кнопка на дашборде).

Распознавание речи идёт через **серверный Whisper** (Free) или **Whisper / Deepgram** (Pro). Локальный Whisper-sidecar в desktop больше не используется.

## Обновление

NOVA проверяет обновления при запуске. При новой версии появится уведомление **«Доступно обновление»**.

- Можно скачать и установить из приложения.
- Кнопка **«Позже»** скрывает уведомление до следующего запуска.
- Либо вручную скачайте новый `NOVA-Assistant-Setup-x64.exe` с сайта и установите поверх.

---

## Удаление

**Параметры → Приложения → Установленные приложения → NOVA Assistant → Удалить**.

Пользовательские данные:

```text
%APPDATA%\nova-assistant-desktop\
```

Удалите эту папку вручную, только если нужна полная очистка (настройки, локальные ключи, история).

## Частые проблемы при установке

| Симптом | Что сделать |
|---|---|
| SmartScreen / «неизвестный издатель» | Ожидаемо для неподписанного установщика. Скачайте с сайта → **Подробнее → Всё равно запустить** |
| Браузер удалил `.exe` | **Оставить** файл в загрузках; источник — только официальный сайт |
| Установщик не стартует | Проверьте `winver`: Windows 10 1903+ или Windows 11, x64 |
| Нет звука / не слышит | Разрешения микрофона Windows + **Настройки → Голос и микрофон** |
| Wake не реагирует | Включите **Wake word** и **Фоновый режим** или используйте кнопку микрофона |
| ИИ не отвечает | Войдите в аккаунт, проверьте интернет и квоту Free/Pro |
