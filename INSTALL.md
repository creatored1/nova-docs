## Установка

### 1. Запустите установщик

Дважды кликните по `.exe`. Если Windows SmartScreen показывает предупреждение — **«Подробнее» → «Всё равно запустить»** (подпись EV появится в следующих релизах).

### 2. Мастер установки

- Выберите папку (по умолчанию `C:\Users\<вы>\AppData\Local\Programs\NOVA Assistant`)
- Создайте ярлык на рабочем столе при необходимости
- Нажмите **Установить**

### 3. Первый запуск

**Микрофон** — обязательно разрешите доступ (Параметры → Конфиденциальность → Микрофон → NOVA Assistant).

**Аккаунт** — войдите или зарегистрируйтесь. ИИ по умолчанию: **Timeweb AI (Gemini 3.1 Flash Lite)**.

**Свои ключи (опционально):** Настройки → ИИ → Anthropic или Google AI. Ключи хранятся только на вашем ПК.

### 4. Проверка

> **«Нова, привет»**

Если ассистент ответил — установка успешна. В трее появится иконка NOVA, на экране — NovaIsland (Pro) или дашборд.

## Настройка микрофона

1. **Пуск → Параметры → Конфиденциальность → Микрофон** — доступ для приложений включён
2. **Пуск → Параметры → Система → Звук → Вход** — выбран нужный микрофон
3. В NOVA: **Настройки → Голос → Устройство ввода**

---

## Wake word и Brain v3

- Фоновый **VAD → Deepgram STT → фраза «Нова, …»** (не Porcupine).
- После активации **follow-up ~10 мин** без повторного wake.
- **PTT** на дашборде или **горячая клавиша** — тот же микрофон.

## Обновление

NOVA проверяет обновления при запуске (`electron-updater`). Уведомление в трее или **Настройки → О программе → Проверить обновления**.

---

## Удаление

**Пуск → Параметры → Приложения → NOVA Assistant → Удалить**

Данные: `%APPDATA%\nova-assistant-desktop\`. Удалите папку вручную для полной очистки.

## Проблемы

| Симптом | Решение |
|---|---|
| SmartScreen блокирует | Подробнее → Всё равно запустить |
| Нужен Visual C++ | [vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe) |
| Установщик не стартует | `winver` — нужен Windows 10 1903+ |
| Не слышит микрофон | См. раздел «Настройка микрофона» |
