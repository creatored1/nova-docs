## Что такое NOVA?

NOVA — настольное приложение для Windows 10/11. Оно открывает программы, управляет окнами и звуком, работает с браузером и файлами, запускает ваши сценарии и отвечает на вопросы через ИИ.

Системные действия выполняются на вашем ПК. Для входа, распознавания речи, озвучки и облачного ИИ нужен интернет.

## Системные требования

| Компонент | Требование |
|---|---|
| ОС | Windows 10 (1903+) или Windows 11, 64-бит |
| Место | Установщик **0.4.4** — около **287 МБ** |
| Интернет | Вход, STT/TTS, ИИ |
| Микрофон | Голос и фоновое прослушивание |

Установщик **без цифровой подписи** — Windows может показать SmartScreen. Как установить безопасно: [INSTALL.md](./INSTALL.md).

## Быстрый старт

1. Скачайте `NOVA-Assistant-Setup-x64.exe` на [nova-assistant.ru/download](https://nova-assistant.ru/download).
2. При предупреждении SmartScreen: **Подробнее → Всё равно запустить**.
3. Установите, разрешите микрофон, войдите через **Telegram** или **VK ID**.
4. Откройте **Настройки** и настройте микрофон, пробуждение и озвучку — [SETTINGS.md](./SETTINGS.md).
5. На дашборде нажмите микрофон или включите wake в **Настройки → Пробуждение**.

## Как устроен голос (Brain v4)

```text
Wake / кнопка микрофона → распознавание речи → маршрутизация
                              ├─ системная команда
                              ├─ ваша команда (граф)
                              ├─ короткие реплики без ИИ
                              └─ диалог с ИИ
```

- Распознавание: **серверный Whisper** (Free) или **Whisper / Deepgram** (Pro).
- Озвучка: **Silero**; на Pro — **Fish Audio**.
- Wake: детект речи (VAD) → распознавание → проверка фразы активации.
- При включённом Wake word команды начинаются с фразы («Нова» / ваши теги), кроме подтверждений.
- Кнопка микрофона на дашборде и фоновое прослушивание делят один микрофон.

## Тарифы

| Возможность | Free | Pro |
|---|---|---|
| Запросы ИИ | 50 / UTC-сутки | 1500 / месяц |
| STT | Серверный Whisper | Whisper или Deepgram |
| TTS | Silero v4 | + Fish Audio |
| Голоса | Ксения, Евгений | + Нова, Мита, Джарвис, Диппер, Рик Санчес |
| NovaIsland | ✓ | ✓ |
| 3D VRM-аватар | — | ✓ |
| Agent и Vision | — | ✓ |

Квота считается для диалога с ИИ (`chat` / `voice_turn`). **Системные команды бесплатны** и работают после исчерпания квоты.
