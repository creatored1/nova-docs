## Что такое NOVA?

NOVA — голосовой ассистент для Windows (Electron), который управляет компьютером по голосу: открывает приложения, регулирует звук, работает с файлами, ищет в браузере и отвечает на вопросы через Brain v3.

В отличие от облачных ассистентов, NOVA работает как настольное приложение на вашем ПК. Системные команды выполняются локально; STT, TTS и облачный ИИ требуют интернет.

## Установка

1. Скачайте установщик на [nova-assistant.ru/download](https://nova-assistant.ru/download) или в [Releases](../../releases).
2. Запустите `NOVA-Assistant-Setup-x64.exe` и следуйте мастеру NSIS.
3. При первом запуске разрешите доступ к микрофону.
4. Войдите в аккаунт NOVA — по умолчанию работает **Timeweb AI (Gemini 3.1 Flash Lite)** без своих ключей.
5. Скажите **«Нова, …»** или удерживайте PTT — ассистент готов.

Подробнее: [INSTALL.md](./INSTALL.md)

## Brain v3 — голосовой конвейер

```
Wake / VAD → STT (Deepgram) → Intent → Router
                                      ├─ System (204+ команд, desktop-only)
                                      ├─ Graph (пользовательские сценарии)
                                      ├─ Social (реплики персонажа без LLM)
                                      └─ LLM (Timeweb AI / Gemini)
```

- **Wake word:** фоновый VAD → STT → проверка фразы «Нова, …» (не Porcupine).
- **Follow-up:** ~10 минут после активации без повторного wake.
- **PTT и горячая клавиша** — один микрофон для wake и команд.

## Как использовать

### Wake word

```
Нова, открой браузер
Нова, сделай скриншот
Нова, какая погода?
```

### Push-to-talk

Нажмите и удерживайте кнопку микрофона на дашборде или горячую клавишу.

### NovaIsland

Компактный оверлей показывает статус: **жду · слушаю · отвечаю · выполняю · сплю**.

## FAQ

Краткие ответы — ниже; полный список в [FAQ.md](./FAQ.md).

**Нужны ли свои API-ключи?**  
Нет для базового использования — Timeweb AI (Gemini) включён по умолчанию. Опционально: Anthropic или Google AI в настройках (хранятся локально).

**Работает ли на Windows 10?**  
Да, Windows 10 (1903+) и Windows 11, 64‑бит. Один установщик для обеих ОС.

**Как работает wake word?**  
VAD → Deepgram STT → проверка «Нова, …». Обязательный wake можно включить или выключить в настройках.
