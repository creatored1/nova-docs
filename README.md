## Что такое NOVA?

NOVA — настольный голосовой ассистент для Windows. Он открывает приложения, управляет окнами, звуком и файлами, работает с браузером, запускает пользовательские сценарии и отвечает на вопросы через ИИ.

Прямые системные действия выполняются локально на компьютере. Для распознавания речи, синтеза и облачного ИИ требуется интернет; режим распознавания зависит от тарифа и настроек.

## Системные требования

| Компонент | Требование |
|---|---|
| ОС | Windows 10 (1903+) или Windows 11, 64-бит |
| Место на диске | Установщик версии 0.3.4 — около 333 МБ; оставьте запас под модели Whisper и данные |
| Интернет | Нужен для входа, облачного STT/TTS и ИИ-ответов |
| Микрофон | Нужен для голосовых команд и фонового wake |

## Установка

1. Скачайте `NOVA-Assistant-Setup-x64.exe` на [странице загрузки](https://nova-assistant.ru/download).
2. Запустите установщик и выберите папку в мастере установки.
3. При первом запуске пройдите настройку микрофона и войдите через Telegram или VK ID.
4. Для Free по умолчанию доступен **DeepSeek V4 Flash** через NOVA; для Pro по умолчанию — **Gemini 3.1 Flash Lite**.
5. На дашборде нажмите кнопку микрофона или включите wake в **Настройки → Голос**.

Подробные шаги: [INSTALL.md](./INSTALL.md).

## Brain v3 — голосовой конвейер

```text
Wake / PTT → STT → Intent → Router
                         ├─ System — системные команды Windows
                         ├─ Graph — пользовательские сценарии
                         ├─ Social — короткие реплики без LLM
                         └─ LLM — диалог и сложные запросы
```

- **Wake:** VAD → распознавание речи → проверка фразы активации. Это не Porcupine.
- **Follow-up:** после активации можно продолжать диалог без повторного wake примерно 10 минут.
- **PTT:** кнопка микрофона дашборда и фоновое прослушивание используют общий микрофон.
- **Graph:** визуальный конструктор команд с действиями, ответами, условиями и подтверждениями.

## Как использовать

### Wake word

Сначала включите **Wake word** и фоновое прослушивание в **Настройки → Голос**, затем говорите:

```text
Нова, открой браузер
Нова, сделай скриншот
Нова, какая погода?
```

По умолчанию wake отключён. Можно настроить фразы активации в том же разделе.

### Кнопка микрофона

Нажмите кнопку микрофона на дашборде, скажите команду и нажмите её снова для завершения разговора. При включённом автоопределении тишины запись может завершиться сама.

### NovaIsland

Компактный оверлей доступен на Free и Pro и показывает состояния **жду · слушаю · отвечаю · выполняю · сплю**. 3D VRM-аватар — отдельная функция Pro.

## Тарифы

| Возможность | Free | Pro |
|---|---|---|
| Платные запросы | 50 за UTC-сутки | 1500 за UTC-месяц |
| STT | Локальный Whisper | Локальный Whisper или Deepgram |
| TTS | Silero v4 | Fish Audio |
| Голоса | Ксения, Евгений | Nova, Mita, Jarvis, Dipper |
| NovaIsland | ✓ | ✓ |
| 3D VRM-аватар | — | ✓ |

Квота учитывает только `chat` и `voice_turn`. Системные команды не списываются и продолжают работать после исчерпания квоты ИИ.

## Голосовые команды

Каталог синхронизирован с текущим приложением и содержит 257 базовых codegen-команд, а также дополнительные сервисные команды, доступные в интерфейсе. Полный список: [COMMANDS.md](./COMMANDS.md).

Примеры:

| Категория | Пример |
|---|---|
| Приложения | «Нова, открой Telegram» |
| Окна | «Нова, сверни окно» |
| Звук | «Нова, сделай громче» |
| Браузер | «Нова, найди рецепт борща» |
| Файлы | «Нова, открой загрузки» |
| Питание | «Нова, заблокируй экран» |

Опасные действия, например выключение компьютера, требуют подтверждения.

## Свои ключи и данные

Свои ключи ИИ можно добавить в **Настройки → ИИ**. Поддерживаются Anthropic, Google AI, OpenAI, Mistral, DeepSeek, OpenRouter и OpenCode — доступность зависит от выбранного провайдера.

Настройки и пользовательские ключи хранятся локально. При использовании облачного STT/TTS или ИИ соответствующие аудио и тексты передаются выбранному провайдеру.
