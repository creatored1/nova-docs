# Настройка NOVA в приложении

Все основные параметры находятся в разделе **Настройки** (иконка шестерёнки в боковой навигации). Вверху панели есть **поиск** по названиям пунктов. После изменений нажмите **Сохранить**.

Актуальная версия приложения: **0.4.4**.

---

## С чего начать

Рекомендуемый порядок после установки:

1. **Голос и микрофон** — устройство ввода, чувствительность, язык распознавания.
2. **Пробуждение** — Wake word и фоновый режим.
3. **Озвучка** — голос и громкость ответов.
4. **Интерфейс** — язык и внешний вид.
5. По желанию: **Модель ИИ**, **Характер ИИ**, **Визуализация**, **Подтверждения**.

Проверка: на дашборде нажмите микрофон и скажите короткую фразу.

---

## Разделы настроек

### Интерфейс

| Параметр | Зачем |
|---|---|
| Язык интерфейса | Русский / English — язык UI и ответов ассистента |
| Оптимизация | Снижает нагрузку (без 3D-аватара; встроенный API не поднимается — нужен Docker или удалённый API). После смены перезапустите NOVA |
| Акцентный цвет / цвет интерфейса | Цвета подсветок и панелей |
| Анимации | Плавные переходы; можно выключить на слабом ПК |
| Лёгкий UI | Меньше glass-blur (часто включено в установщике) |
| Стиль стекла | Лёгкий / сбалансированный / полный / свой; слайдеры прозрачности и «глубины» |

### Подтверждения

Как NOVA спрашивает «выполнить?» перед командой и доступом к экрану:

- **Визуально (окно)** — всплывающее окно.
- **Голосом** — скажите «да» / «нет».
- **Автоматически** — обычные подтверждения пропускаются.

**Критичные команды** (выключение, перезагрузка, сон, выход из Windows) **всегда** требуют явного подтверждения, даже в авто-режиме.

### Голос и микрофон

| Параметр | Зачем |
|---|---|
| Модель распознавания | Free: серверный **Whisper**. Pro: **Whisper** или облачный **Deepgram** |
| Качество распознавания | Пресет микрофона + STT; «Максимальное» задействует Deepgram (Pro) |
| Язык распознавания | Авто / русский / English |
| Микрофон | Устройство ввода (или системное по умолчанию) |
| Чувствительность микрофона | Выше — если говорите тихо; слишком высоко — больше шума |
| Порог VAD | Выше — строже к фону, позже старт фразы |

Без рабочего микрофона в Windows голосовые команды не заработают: **Параметры Windows → Конфиденциальность → Микрофон**.

### Пробуждение

| Параметр | Зачем |
|---|---|
| Wake word | Вкл: команды начинаются с фразы активации (кроме подтверждений). Выкл: можно говорить и без «Нова» |
| Фоновый режим | Вкл: NOVA слушает в фоне. Выкл: только кнопка микрофона на дашборде |
| Фразы активации | До 25 тегов. По умолчанию `NOVA` и `НОВА`. Enter или пробел — добавить |

Типичная схема «как Алиса»: включите **Wake word** и **Фоновый режим**, затем говорите:

```text
Нова, открой Telegram
Нова, сделай громче
```

После одной только фразы «Нова» у вас есть короткое окно (~30 с), чтобы произнести саму команду.

### Озвучка

| Параметр | Зачем |
|---|---|
| Движок | **Silero v4** (базовый) или **Fish Audio** (Pro) |
| Голос | Ксения, Евгений; на Pro — Нова, Мита, Джарвис, Диппер, Рик Санчес и др. |
| Тихий режим | Только текст, без речи |
| Громкость озвучки | Уровень TTS |
| Тест | Прослушать выбранный голос |

Прослушать можно любой голос; **выбрать** Pro-голос для постоянной озвучки можно на тарифе Pro.

### Характер ИИ

Стиль речи и тон ответов в голосовых командах и чате. Выберите готовый образ или задайте свой. Голос TTS настраивается отдельно в **Озвучке**.

### Модель ИИ

| Параметр | Зачем |
|---|---|
| AI-провайдер | **NOVA** (встроенный) или свой ключ: OpenAI, Mistral, DeepSeek, OpenRouter, OpenCode, Anthropic, Google |
| Модель | Список зависит от провайдера и тарифа |
| Температура | 0 — точнее, 1 — свободнее |
| Уровень рассуждения | Для части моделей OpenAI / Mistral |
| API-ключи | Хранятся локально на вашем ПК |

На **Free** через NOVA по умолчанию — **DeepSeek V4 Flash**.  
На **Pro** — **Gemini 3.1 Flash Lite**, **GPT-5.4 Nano** и др. (см. актуальный список в настройках).

### Визуализация

Поверх окон можно показать:

- **Выключено**
- **Островок (NovaIsland)** — компактный статус: слушаю / отвечаю / выполняю и т.д. (Free и Pro)
- **3D-аватар** — VRM-модель (Pro); можно загрузить свою `.vrm` до 64 МБ

Островок и аватар взаимоисключающие: включение одного выключает другой.

В **exclusive fullscreen** (многие игры DirectX) оверлеи скрываются, чтобы Windows не сворачивала игру. Команды и голос продолжают работать; подтверждения — голосом («да» / «нет»).

### Работа с файлами

Список дисков и папок, где NOVA может искать, открывать и читать файлы (Документы, Рабочий стол, Загрузки, папки NOVA Documents / Presentations / Spreadsheets и ваши пути). Добавляйте только нужные каталоги.

### Режим агента (Pro)

Многошаговые задачи с отдельными разрешениями (мышь, клавиатура, окна, файлы, сеть). Обычные голосовые команды работают и без агента. Доступно в desktop-приложении на Pro.

### Vision режим (Pro)

- **Чтение экрана** — дерево UI и снимки для описания содержимого.
- **Управление экраном** — клики, ввод, жесты.

Перед действиями NOVA запрашивает согласие (см. также подтверждения). Только desktop + Pro.

### Система

Уведомления Windows и **автозапуск** при входе в Windows.

### О приложении

Версия NOVA, открытие папки с **логами**, сведения для поддержки.

## Как пользоваться после настройки

### Кнопка микрофона (дашборд)

1. Нажмите микрофон — начался живой диалог.
2. Говорите.
3. Нажмите ещё раз — завершить. При авто-тишине запись может остановиться сама.

Кнопку **не нужно удерживать**.

### Wake + фон

При включённых **Wake word** и **Фоновом режиме** вызывайте NOVA фразой активации из любой программы (пока микрофон разрешён системе).

### Текстовый чат

На дашборде можно писать запросы текстом — удобно, если микрофон занят или нужно вставить длинный текст.

## Тарифы (кратко)

| | Free | Pro |
|---|---|---|
| Запросы ИИ | 50 / сутки (UTC) | 1500 / месяц |
| STT | Серверный Whisper | Whisper или Deepgram |
| TTS | Silero | + Fish Audio |
| NovaIsland | ✓ | ✓ |
| 3D-аватар, Agent, Vision | — | ✓ |

Системные команды **не расходуют** квоту ИИ.

Подробнее о тарифах и оплате — в разделе **Аккаунт** в приложении и на [nova-assistant.ru](https://nova-assistant.ru).
