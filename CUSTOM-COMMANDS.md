# Свои (кастомные) команды

В NOVA есть два типа команд:

| Тип | Где | Что это |
|---|---|---|
| **Системные** | **Команды → Системные** | Готовые действия NOVA (открыть приложение, громкость, окна…) — [COMMANDS.md](./COMMANDS.md) |
| **Свои** | **Команды → Свои** | Ваши сценарии на визуальном холсте: фраза → шаги → ответ |

Этот гайд про **свои** команды.

---

## Зачем они нужны

Соберите цепочку под одну фразу, например:

- «Нова, рабочий режим» → свернуть всё → открыть браузер → открыть Telegram → сказать «Готово».
- «Нова, фокус» → выключить звук → включить «Не беспокоить» (через ваши шаги) → уведомление.

Так вы не повторяете длинные инструкции каждый раз.

---

## Быстрый старт

1. Откройте раздел **Команды** в боковой навигации.
2. Перейдите на вкладку **Свои** (или создайте новую команду кнопкой вроде **Новая** / **+**).
3. Задайте **название** и **фразы-триггеры** (что нужно сказать).
4. На холсте соберите узлы: **триггер → действие(я) → ответ** (и при необходимости условия / подтверждение).
5. **Сохраните** команду и убедитесь, что она **включена**.
6. Проверьте:
   - кнопкой **Запустить** в панели команды, или
   - голосом (с wake-фразой, если wake включён).

---

## Узлы на холсте

Типичный сценарий:

```text
[Триггер] → [Действие] → [Действие] → [Ответ]
                ↓
           [Подтверждение]   (для опасных шагов)
                ↓
           [Условие] → ветка «да» / «нет»
```

| Узел | Назначение |
|---|---|
| **Триггер** | Фразы активации сценария (можно несколько) |
| **Действие** | Конкретный шаг: открыть приложение, громкость, горячая клавиша, системная команда NOVA и т.д. |
| **Ответ** | Что сказать или показать пользователю; можно с вариантами ответов |
| **Подтверждение** | Спросить «выполнить?» голосом/окном перед опасным шагом |
| **Условие** | Ветвление по состоянию (например, проверка перед следующим шагом) |
| **Конец** | Завершение ветки |

Соединяйте узлы: тяните от **выходного** порта к **входному**. Неверные связи блокируются.

---

## Какие действия можно ставить

В редакторе доступны группы действий, в том числе:

- **Система** — системная команда NOVA по фразе, скриншот, корзина, диспетчер задач, блокировка экрана…
- **Приложения** — открыть / закрыть / сфокусировать
- **Окна** — свернуть, развернуть, snap влево/вправо/по углам, рабочий стол…
- **Браузер** — URL, поиск, вкладки, назад/вперёд/обновить
- **Звук** — громче/тише, mute, громкость %, микрофон
- **Клавиатура / мышь** — клавиша, сочетание, последовательность клавиш, ввод текста, управление мышью
- **Таймеры** — таймер и напоминания
- **Папки** — Загрузки, Документы, рабочий стол, корзина
- **Буфер** — прочитать / записать
- **Прочее** — пауза (задержка), уведомление Windows, PowerShell (**выключен по умолчанию** — включайте осознанно)

Перед опасными шагами добавьте узел **Подтверждение**.

## Управление холстом

Те же приёмы, что во встроенной справке редактора (**?** в редакторе команд):

| Действие | Как |
|---|---|
| Добавить узел | ПКМ по пустому холсту |
| Меню узла | ПКМ по узлу — копировать / дублировать / удалить |
| Удалить связь | ПКМ по линии |
| Соединить | Тянуть от выхода к входу |
| Двигать холст | Средняя кнопка мыши (колёсико) + перетаскивание |
| Масштаб | Ctrl + колёсико |
| Выделить несколько | ЛКМ-рамка; Shift — добавить к выделению |
| Переместить узел | ЛКМ-перетаскивание |
| Настройки узла | Двойной клик |
| Удалить | Delete / Backspace |
| Копировать / вставить / дублировать | Ctrl+C / Ctrl+V / Ctrl+D |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z |

## Пример: «Собери рабочий стол»

1. Создайте команду, триггер: `рабочий режим`, `собери стол`.
2. Добавьте действия по порядку:
   - свернуть все окна;
   - открыть браузер / нужный URL;
   - открыть Telegram.
3. В конце — **Ответ**: «Рабочий режим готов».
4. Сохраните и включите команду.
5. Скажите: **«Нова, рабочий режим»** (если wake включён).

---

## Импорт и экспорт

В разделе **Команды** можно **экспортировать** свои сценарии (чтобы сохранить копию или перенести на другой ПК) и **импортировать** ранее сохранённый файл. После импорта проверьте фразы и включённость команды.

Точные кнопки смотрите в панели списка своих команд в приложении.

---

## Советы

1. **Короткие уникальные фразы** — меньше путаницы с системными командами и ИИ-диалогом.
2. **Один сценарий — одна задача**; сложное лучше разбить на несколько команд.
3. Для шагов с риском всегда ставьте **подтверждение**.
4. Если голос не ловит триггер — проверьте **Настройки → Пробуждение** и произношение; запасной путь — кнопка **Запустить**.
5. Системные команды из каталога можно вызывать и из своих сценариев (действие «системная команда NOVA»).

---

## Если сценарий не срабатывает

| Проблема | Проверьте |
|---|---|
| Не реагирует на фразу | Команда включена; wake/фон; нет конфликта с другой фразой |
| Обрывается на шаге | Логи в **Настройки → О приложении**; не блокирует ли подтверждение |
| Не то приложение | Укажите точное имя в действии «открыть приложение» |
| Нужен доступ к файлам | **Настройки → Работа с файлами** — разрешённые папки |
